# 英文法 無限ドリルBOX

中学・高校の英文法を、何度でも新しい問題で練習できる単一HTMLの学習ツールです。
サーバーやビルド不要で、`index.html` をブラウザで開くだけで動きます。

## 主な機能

- 現在形・過去形・完了形・受動態・不定詞・関係詞・比較・助動詞・仮定法など、18の文法単元
- 出題形式を4種類から選択（複数選択可）
  - 穴埋め選択（空所に入る正しい形を4択）
  - 日本語訳選択（英文を読み、正しい日本語訳を選ぶ）
  - 英文選択（日本語を読み、正しい英文を選ぶ）
  - 並べ替え（バラバラの単語を正しい順にクリックして並べる）
- 選んだ単元・出題形式から問題をCSVファイルに書き出す機能（他のクイズツール用、`単元,問題文,赤,青,黄,緑,正解` の形式）
- ライト／ダークモード自動対応

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK）
2. GitHub Pages で公開する場合は、このリポジトリの Settings → Pages で
   ブランチを `main`（フォルダは `/`）に設定すると、
   `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 技術メモ

- 依存ライブラリなしの素のHTML / CSS / JavaScript（単一ファイル）
- 出題される英文・日本語訳はすべて事前に用意された語彙・例文バンクの組み合わせで生成されており、
  外部APIへの通信やAIによる文章生成は行っていません
